# Sample recipes / 示例菜谱

The app includes six opt-in examples under **Recipes → Browse sample recipes**. Save one or all; existing recipes are preserved and each catalog entry is added only once. Templates contain Chinese and English text; saving uses the current interface language. Saved text stays editable and does not change when the interface language changes.

| --- | --- | --- |

| 黑豆芝士夹饼 | Black bean quesadillas | [Good Food · Cassie Best](https://www.bbcgoodfood.com/recipes/cheesy-black-bean-quesadillas) |
| 亲子丼 | Oyakodon | [Just One Cookbook · Namiko Hirasawa Chen](https://www.justonecookbook.com/oyakodon/) |
| 韩式凉拌黄瓜 | Korean cucumber salad | [Maangchi](https://www.maangchi.com/recipe/oi-muchim) |

These are concise adaptations with adjusted portions, not verbatim copies or nutritional analyses of the source dishes. Quantities, raw/cooked states and unmeasured seasonings are explicit. Examples do not include preset photos. Previously added images were removed at the user's request; the recipe text and source links remain.

The original tomato-and-eggs starter recipe is still available for an empty library. Older prototype catalog ideas are not imported automatically.
